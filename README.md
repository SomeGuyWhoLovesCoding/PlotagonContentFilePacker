# PlotagonContentFilePacker

How to use:

Download Main.exe, create a folder to move it in and feel free to pin the tab to quick access if you're me

You should see this:

```
PCF Tool
  pcf_tool unpack <input.pcf>    <output_folder>
  pcf_tool pack   <input_folder> <output.pcf>
```

Then you can navigate around ocne you successfully unpack and start modifying!

You can drag your plotagon pcf file to the same location as the main
